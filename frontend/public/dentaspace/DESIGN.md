# DentASpace

> Category: Brands

> Surface: web

*système de gestion de cabinet dentaire*

DentASpace is a dental practice management web app — patients, appointments, invoicing.

## Color Palette

| Role | Name | Hex | Usage |
| --- | --- | --- | --- |
| background | Surface | `#ffffff` | page canvas |
| foreground | Primary | `#191919` | body text and headings |
| accent | Secondary | `#57c8cb` | primary actions and emphasis |
| surface | Surface | `#f0fdfa` | cards and panels |
| muted | Muted | `#64748b` | secondary text and metadata |
| border | Border | `#e2e8f0` | rules and dividers |
| accent-secondary | Accent | `#0d9488` | secondary actions and links |

## Typography
- **Display:** Inter — weights 400, 600, 700 — fallbacks: system-ui, -apple-system, Segoe UI, Helvetica Neue, Arial, sans-serif
- **Body:** Inter — weights 400, 500 — fallbacks: system-ui, -apple-system, Segoe UI, Helvetica Neue, Arial, sans-serif

## Voice & Tone

- **Adjectives:** clean, clinical, approachable, modern
- **Tone:** professionnel et rassurant pour les patients, efficace pour les secrétaires

### Messaging pillars
- Gestion de cabinet dentaire simple et moderne
- Prise de rendez-vous, patients, facturation
- Application mobile-first pour les patients, responsive pour les secrétaires

### Vocabulary
- **Use:** cabinet dentaire, patients, rendez-vous, secrétaires, soins dentaires, planning
- **Avoid:** jargon technique non nécessaire, termes trop médicaux

## Imagery

- **Style:** clean photography, minimalist illustrations, dental/medical context
- **Subjects:** dental clinic environment, patient care moments, happy smiles
- **Treatment:** bright, high-key, warm clinical lighting
- **Avoid:** graphic medical imagery, blood, invasive procedures

## Layout

- **Radius:** 8px
- **Border weight:** 1px
- **Spacing:** 8px baseline grid

### Posture rules
- Cards use 8px radius, 1px #e2e8f0 border, subtle shadow on hover
- Accent #5ce1e6 used sparingly — one hero element per screen max
- Dark text #191919 on white #ffffff for primary readability
- Surface #f0fdfa for card backgrounds, never pure gray
- Green #10b981 for success/confirmed states only
